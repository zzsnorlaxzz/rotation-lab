# 회전 실험실

평면도형을 직접 그리고 회전체 생성 과정과 단면을 탐구하는 React · TypeScript · Three.js 웹 앱입니다.

실행: https://zzsnorlaxzz.github.io/rotation-lab/

## 조작

- 점·선분으로 다각형을 그리거나 호·반원 도구로 중심에서 바깥쪽으로 드래그합니다. 기본값은 반원(180°)이며 호 각도를 30°~180°로 조절합니다. 호의 양 끝점을 잇는 점선이 회전 영역을 닫습니다. 회전축 위에 중심을 놓은 반원은 구를 만듭니다.
- 주황색 점을 잡고 좌우로 드래그하면 도형이 0~360° 회전합니다. 반대로 움직이면 입체도 되감깁니다.
- 빈 공간을 잡고 드래그하면 카메라 시점만 바뀝니다. 모드 전환이 필요 없고 드래그 도중에 동작이 서로 바뀌지 않습니다.
- 두 손가락 확대·축소, 휠, 각도 슬라이더·바로가기, 자동 회전과 일시정지를 지원합니다.
- 360° 완성 후 두 방향으로 실제 입체를 잘라 단면을 관찰합니다. 절단 단계에서는 드래그가 시점만 바꿉니다.
- 도형 변경·예제 변경·되돌리기·초기화는 각도와 이전 단면 상태를 초기화합니다.

## 소스 수정과 자동 배포

Node.js 24에서 아래 명령을 실행합니다.

```sh
npm ci
npm run dev
npm test
npm run build
```

main 브랜치에서 파일을 수정하고 커밋하면 GitHub Actions가 검사·빌드 후 GitHub Pages에 자동 배포합니다. Actions 탭에서 성공 여부와 로그를 확인하세요. 워크플로는 .github/workflows/pages.yml입니다.

- src/Editor.tsx: 모눈 평면과 다각형·호 편집
- src/Scene.tsx: Three.js 장면과 포인터 조작
- src/interaction.ts: 주황색 점 판별, 드래그 각도 계산
- src/geometry.ts: 회전체와 단면 계산
- src/main.tsx, src/style.css: 화면과 안내

빌드 결과 dist/index.html은 스타일과 라이브러리를 포함한 독립 실행 파일로, 브라우저에서 직접 열어 오프라인에서도 실행할 수 있습니다. WebGL이 필요합니다. 새로고침하면 작업은 초기 상태로 돌아갑니다.

## 계산과 검증

사용자가 그린 다각형을 Y축 둘레로 현재 각도만큼 쓸어 부분 표면을 생성하고 시작·끝 면을 막습니다. 오목한 다각형과 내부 구멍을 유지합니다. 가로 단면은 해당 높이에서 다각형과 교차하는 반지름 구간을 원 또는 고리로 만들며 여러 구간도 지원합니다. 세로 단면은 축 양쪽의 대칭 영역을 표시합니다. 실제 표면 클리핑과 단면 메시를 사용합니다.

호는 중심·반지름·호 각도로 보존하고 96개 구간으로, 회전 표면은 최대 3° 간격으로 근사합니다. 자유 곡선, 회전축 이동, 부피 계산, 여러 도형 동시 회전은 포함하지 않습니다.

자동 검사: 기하 20개 사례, 주황색 점/빈 공간 구분, 두 관찰 단계와 절단 단계, 되감기 및 각도 제한.

## 마우스로 호 그리기

중심에서 바깥쪽으로 드래그해 중심·반지름을 정한 뒤, 파란 끝점을 원둘레를 따라 드래그합니다. 중심·반지름과 반대쪽 끝점이 유지되어 실제 호를 따라 그릴 수 있습니다. 호·반원 도구 또는 선택·이동 도구에서 끝점을 잡을 수 있습니다. 선택·이동 도구의 중심과 오른쪽 반지름 손잡이는 기존 조작을 유지합니다. 끝점이 반지름 손잡이와 겹치면 호·반원 도구에서는 끝점, 선택·이동 도구에서는 반지름을 조절합니다. 호는 회전축 오른쪽 반원 안에서 30°~180° 범위로 그립니다. 드래그 중 모양을 미리 보여주고 손을 놓으면 한 작업으로 확정되어 되돌릴 수 있습니다.

## 한 화면 실험실과 회전 조작

단계 이동 없이 왼쪽의 평면 편집과 오른쪽의 3D 회전체를 동시에 봅니다. 도형이 완성되면 즉시 오른쪽에서 회전할 수 있습니다. 주황색 점뿐 아니라 도형 표면을 잡아도 회전합니다. 빈 공간 드래그는 시점만 바꿉니다. 아래의 큰 주황색 회전 바, 항상 보이는 각도 슬라이더, 0°·90°·180°·270°·360° 버튼, 숫자 입력, 자동 회전도 사용할 수 있습니다. 드래그 감도는 화면 너비에 맞추고, 0° 또는 360°에 도달한 뒤에는 반대 방향으로 움직이는 즉시 되감깁니다. 단면 도구는 왼쪽 ‘표시와 단면 도구’에 있습니다. 작은 화면에서는 위아래로 배치합니다.
