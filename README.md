# 회전 실험실

React · TypeScript · Three.js로 평면도형, 회전체 생성 과정과 단면을 탐구합니다.
실행: https://zzsnorlaxzz.github.io/rotation-lab/

## 조작

- 왼쪽에서 점·선분으로 닫힌 다각형을 그립니다. ‘확대’를 누르면 큰 편집창에서 같은 그림을 이어 그릴 수 있습니다. 완료 또는 Escape로 돌아옵니다.
- 호·반원은 중심에서 드래그해 반지름을 정하고 파란 끝점을 끌어 호를 그립니다. 중심·반지름 수정도 지원합니다. 호는 끝점을 연결하지 않으며 내부를 채우지 않는 열린 곡선입니다. 열린 호에는 부피와 단면을 생성하지 않습니다. 부채꼴 도구는 아직 포함하지 않습니다.
- 3D 공간의 모든 드래그는 카메라 시점만 변경합니다. 도형 회전은 아래 각도 슬라이더에서 조절합니다. 제목과 회전 조작 영역을 줄여 3D 화면을 넓혔습니다. 자동 회전은 제공하지 않습니다.
- 항상 보이는 ‘세로 단면’·‘가로 단면’ 버튼을 누르면 360°로 완성한 뒤 실제 입체를 잘라 봅니다. 바로 아래에서 절단 위치, 평면 표시, 한쪽 숨기기, 원래 도형 비교, 단면 정면 보기를 조절합니다.
- 휠·두 손가락과 확대·축소 버튼, 입체·앞·위·자유 시점을 지원합니다. 도형 변경·되돌리기·초기화는 각도와 단면을 초기화합니다.

## 실행과 배포

Node.js 24에서:

```sh
npm ci
npm run dev
npm test
npm run build
```

main에 커밋하면 GitHub Actions가 검사·빌드 후 GitHub Pages로 배포합니다. 워크플로는 .github/workflows/pages.yml입니다. 빌드한 dist/index.html은 브라우저에서 직접 여는 독립 실행 파일이며 WebGL이 필요합니다. 새로고침하면 작업은 초기화됩니다.

## 구현

src/Editor.tsx는 다각형·열린 호 편집, src/Scene.tsx는 3D 시점과 실제 클리핑, src/geometry.ts는 회전 표면과 단면, src/main.tsx와 src/style.css는 화면을 담당합니다. 부분 회전의 양 끝 면, 오목한 다각형, 고리·분리된 가로 단면, 세로 대칭 단면을 계산합니다. 호는 96개 선분으로 근사하고 열린 연결 정보를 보존합니다. 자유 곡선, 회전축 이동, 부피 계산과 여러 도형 동시 회전은 포함하지 않습니다.

npm test는 20개 기하 사례와 시점/회전 조작의 분리 및 각도 경계를 검증합니다.

선분 도구는 두 번 클릭할 때마다 선분 하나를 완성합니다. 다음 선분은 시작점을 다시 찍습니다. 기존 점을 우선 잡고 정수 좌표는 0.34칸 이내에서 스냅하며 반 칸 모눈도 유지합니다. 마우스 좌표와 예상 선분을 표시합니다. 확대 편집창은 화면 너비와 높이의 98%를 사용하며 불필요한 왼쪽 여백을 줄였습니다.

호를 그린 뒤에도 선분 도구를 사용할 수 있습니다. A·B 끝점을 연결하거나 중심을 경유해 사용자가 직접 닫은 경우에만 회전 영역을 생성합니다. 호의 중심·반지름·각도를 수정해도 연결한 선분을 유지합니다. 격자는 정수 한 칸만 표시하고 축 눈금과 호 보조선을 줄였습니다.

닫힌 도형을 완성하거나 호 그리기를 마치면 이동 도구로 자동 전환합니다. 예제도 이동 도구로 시작하며 초기화·새로 그리기는 선분 도구로 시작합니다.

확대 편집창 오른쪽의 도형 바로 만들기 버튼으로 직사각형·직각삼각형·반원·사다리꼴을 불러옵니다. 기존 그림을 바꾸며 되돌리기로 복원할 수 있습니다. 반원 버튼은 지름까지 연결된 닫힌 반원 부채꼴을 만듭니다. 직접 그리는 호 도구와 열린 반원 예제는 자동으로 닫지 않습니다. 불러온 뒤 이동 도구가 선택되며 회전 각도와 단면은 초기화됩니다.
